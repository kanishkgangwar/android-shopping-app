# Android Shopping App

Modern Android shopping app built using Kotlin and Jetpack Compose.

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Room Database
- Retrofit
- Hilt Dependency Injection
- StateFlow

## Features
- User Authentication
- Product Listing
- Search Functionality
- Cart Management
- Profile Settings
- Local Database Storage

## API
Products fetched using:
https://api.escuelajs.co/api/v1/
